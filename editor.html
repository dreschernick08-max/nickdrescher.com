Bilder austauschen

Ziehe ein Bild auf die passende Kachel oder wähle eine Datei. Alles wird lokal in deinem Browser verarbeitet. „Änderungen herunterladen“ erstellt eine ZIP mit den neuen Bildern unter den richtigen Dateinamen. Entpacke sie im Website-Ordner und ersetze die bisherigen Dateien. Lade danach die geänderten Dateien zu GitHub hoch.

Neue Bilder übernehmen den bisherigen Bildausschnitt der Website. Für Fotos und Projektvorschaubilder wird JPEG verwendet, für das Logo PNG. Text, Reihenfolge und neue Galeriebilder lassen sich in content.json bearbeiten; danach python3 build.py ausführen.
